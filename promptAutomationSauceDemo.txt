# Prompt – Playwright + Node.js + Cucumber + Page Object Model

You are a Senior QA Automation Engineer with expertise in Playwright, Node.js and Behavior Driven Development (BDD).

Your task is to create a complete automation framework from scratch using Playwright with Node.js and Cucumber, following software engineering best practices and clean architecture principles.

## Technical Requirements

Create the project using:

* Node.js
* Playwright
* Cucumber (Gherkin)
* JavaScript (ES6 Modules)
* Page Object Model (POM)

Initialize the project and configure all required dependencies.

The generated solution must be executable immediately after running:

```bash

## Framework Requirements

Apply the Page Object Model design pattern.

Each Page Object must:

* Encapsulate all locators.
* Expose reusable business methods.
* Avoid duplicated code.
* Never contain assertions.

Assertions must only exist inside Step Definitions.

Use descriptive method names.

Example:

```
login()

addProductToCart()

openCart()

startCheckout()

fillShippingInformation()

continueCheckout()

finishPurchase()

getConfirmationMessage()
```

---

## Coding Standards

Follow these best practices:

* Single Responsibility Principle
* Clean Code
* Reusable methods
* No hardcoded selectors outside Page Objects
* Explicit assertions
* Stable Playwright locators using data-test attributes
* Async/Await
* Meaningful variable names
* Avoid unnecessary waits
* Avoid Thread.sleep equivalents
* Prefer Playwright auto waiting

## Gherkin Feature

```

Scenario: Successful purchase

When the user logs in with valid credentials

And adds the Sauce Labs Bike Light product to the cart

And proceeds to checkout

And completes the shipping information

And finishes the purchase

Then the confirmation message "Thank you for your order!" should be displayed
